# Kaggle hosting inquiry — draft, not sent

Subject: Hosting a poker-agent simulation competition with four Swiss rounds

We would like to host a poker AI competition on Kaggle, inspired by Kaggriculture and Orbit Wars. Participants would submit agents that compete using virtual chips in a custom poker environment.

Our required final evaluation format is exactly four Swiss-style rounds, with five games per round. Each round pairs teams based on their current match points, avoiding repeat opponents where possible. We propose defining each game as a fixed-length session of many poker hands to reduce card variance, and using aggregate chip profit across the five games to decide the round. We propose freezing one agent version per team for all four rounds and publishing standings and replays after each round.

The poker variant is being finalized; our current proposal is heads-up no-limit Texas Hold'em with stacks reset each hand and paired deals played with swapped seats.

Could you confirm:

1. The process and eligibility requirements for hosting this custom simulation on Kaggle.
2. Whether evaluation supports four discrete Swiss rounds, custom pairings, submission freezing, byes, and our published tie-break rules.
3. If custom scheduling is not supported natively, whether an organizer-run evaluator can integrate with official Kaggle submissions and final standings.
4. The required environment interface, runtime, sandbox limits, replay format, and review process.
5. Hosting costs, compute responsibilities, sponsorship or prize requirements, and expected lead time.

We can provide the environment source, deterministic tests, baseline agents, replay examples, a compute estimate from pilot matches, and a draft competition rulebook.

Organizer details to supply: contact name, organization (if any), expected entrant count, target dates, and available budget/prizes.
