Built for experiments, not promises.

The starter uses simple equity estimates, pot odds, position, and occasional bluffs. It is an educational baseline—not an optimal poker strategy. Short matches are noisy; use 200 paired deals per game for the proposed full workload. This version runs head-to-head practice. Four-round Swiss tournaments are planned.
